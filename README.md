# Hanzala Portfolio

A simple static personal portfolio website built for **CSC418 – DevOps for Cloud Computing, Lab Assignment 01** at COMSATS University Islamabad, Abbottabad Campus.

The site was generated with an AI coding assistant and managed with Git and GitHub.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure and content |
| `style.css` | Layout, colours and responsive design (supports dark mode) |
| `script.js` | Skill filter buttons and footer year |

## Run locally

No build step or dependencies are needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/hanzala261/hanzala-portfolio.git
   ```
2. Open `index.html` in any web browser.

## DevOps workflow used

```bash
git init
git add .
git commit -m "Initial website commit"
git remote add origin <repository-url>
git branch -M main
git push -u origin main
```
